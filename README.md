# Linux CLI Fundamentals Practice

This repository contains my hands-on practice of Linux CLI Fundamentals as part of my DevOps interview preparation. The goal of this repository is to strengthen my Linux fundamentals through practical command-line exercises and build confidence for real-world DevOps tasks and interviews.

## Objectives

- Practice Linux CLI commands through hands-on exercises.
- Understand Linux fundamentals and filesystem navigation.
- Learn commonly used Linux commands for DevOps.
- Improve command-line confidence through regular practice.
